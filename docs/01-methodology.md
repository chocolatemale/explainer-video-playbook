# 方法论：怎么做一支「逐句上屏」的中文科普短片

这份方法论来自一次真实制作：用免费素材、本人音色配音和 AI 代理，做一支 3 分钟的科普视频《选城市的三本账》。第一版做成了暗色电影感，被否了，原因是画面空、没字、画面和旁白对不上。第二版改成下面这套做法后通过。这里写的是第二版的规则，以及第一版为什么错。

---

## 一、风格的核心：画面跟着句子走

一句话概括：**旁白说到哪个词，那个词就出现在画面上。**

| 规则 | 具体做法 | 为什么 |
|---|---|---|
| 句子级节奏 | 约每 2–3 秒画面变一次：切镜头、换讲解板，或者弹出一个贴纸 | 科普视频的观众是在听讲。画面停住超过 4 秒，注意力就散了 |
| 词级同步 | 贴纸、高亮、数字的出现时间，卡在旁白读到这个词的那一帧 | 耳朵和眼睛同时收到同一个词，记得最牢 |
| 两种画面交替 | **实拍满屏**（建立场景和情绪）和 **纸张讲解板**（讲数字、对比、公式）交替出现 | 只有实拍会像宣传片，信息进不去；只有讲解板又像幻灯片 |
| 字短，但要有 | 每个贴纸只放 2–6 个字的关键词或一个数字；全程有底部字幕 | 「字少」不等于「没字」。第一版把「简洁」理解成几乎不上字，失败了 |

### 判断标准（审片时逐条问）
1. 随便暂停在任意一帧，能不能从画面上的字猜到旁白在讲什么？
2. 有没有哪个画面停了超过 4 秒却没有任何变化？
3. 讲解板上的内容有没有占满画面（宽度至少 60%，水平居中），而不是缩在一角？
4. 每个数字都能追溯到来源吗？

## 二、视觉语汇（一套就够，全片不换）

### 色板
| 角色 | 色值 | 用途 |
|---|---|---|
| 纸张底 | `#F4F1E8` | 讲解板背景（暖白，比纯白柔和，像笔记本） |
| 墨色 | `#161616` | 正文、黑底标签 |
| 荧光黄 | `#FFE03A` | 本句最重要的那个词或数字，**每屏最多一处** |
| 红 | `#E8392F` | 反转、提醒、「≠」 |
| 蓝 / 绿 | `#3570E8` / `#1FA971` | 对比项、结论 |
| 灰条 | `#C9C4B8` | 被扣掉、被忽略的部分 |

对比多个对象（例如四座城市）时，每个对象固定一个颜色，全片不变。

### 七种元素
| 元素 | 长相 | 什么时候用 |
|---|---|---|
| **tag 标签** | 白底黑字小方块，放左上角 | 告诉观众「这是哪/这是谁」：城市名、职业 |
| **黄块 chip-y** | 荧光黄圆角块 + 黑字 | 本句的核心概念 |
| **黑块 chip-k** | 黑底白字 | 公式里的项、对照组、章节号 |
| **红贴纸 sticker-r** | 红底白字，倾斜 6–10°，白描边 + 投影 | 反转、设问、「还没算吃饭」这类提醒 |
| **实拍大字 kinetic** | 白字 + 黑描边 + 投影，放在实拍上，可以用黄底高亮其中一个词 | 实拍画面上的关键句或数字 |
| **素材卡片 card** | 实拍静帧，圆角，白边，投影，左上角带 tag | 讲解板上代表一个对象（一座城、一种工作） |
| **彩条 bar** | 横向或竖向的色条，条上压数字 | 数量对比；「工资 − 税 − 房租 = 留下」这种逐行扣减最有效 |

### 动效（全部按绝对帧号计算，可以任意跳帧重渲）
- 贴纸：0.18 秒弹出，缩放 0.6 → 1.08 → 1 回弹
- 卡片：0.3 秒从下方 30px 上浮并淡入
- 彩条：0.5 秒从 0 长到目标长度，数字同步滚动计数
- 不做花哨转场，靠硬切加贴纸弹出制造节奏

### 字幕
底部居中，白字约 48px（以 1080p 计；`noto` 预设仍为 46px），6px 黑描边加柔和投影；按标点断句，每屏最多 16 个字，不带句末标点。默认字幕用霞鹜文楷 Medium，贴纸和实拍大字用得意黑，缺字回退 Noto Sans SC。**字幕文字一律用原稿**，不用语音识别结果（识别会把「城市」写成同音的「程式」）。

## 三、叙事结构：一个框架 + 逐项对比

科普选题最稳的结构是：**抛出一个反直觉的问题 → 给出一个可操作的框架 → 用框架逐项对比 → 回到观众自己。**

以《选城市的三本账》为例：

| 段落 | 时长 | 做什么 |
|---|---|---|
| 钩子 | 0–15 秒 | 四座城快切，然后问一个问题：工资最高的那座，一定最好吗？ |
| 框架 | 15–35 秒 | 「三本账 + 一道门」：钱、机会、时间、门槛。每本账一张卡片 |
| 逐账对比 | 35 秒–2 分 45 秒 | 每本账以章节卡开头，然后是数据讲解板和实拍交替；每本账至少一个「扣掉之后反转」的时刻 |
| 权重 | 约 35 秒 | 框架不是死的：人生阶段不同，各本账的分量也不同 |
| 收束 | 约 20 秒 | 一句结论 + 一个观众能马上做的动作（拿出一张纸打分） |

写稿时注意：
- 每句话只讲一件事，长度控制在 2–4 秒能读完。这样每句天然对应一个画面。
- 每句话里要有一个能上屏的「钩子词」（名词、数字、对比）。写不出钩子词的句子，多半是废话。
- 数字要先在稿里写成读法（「一百五十七万」），上屏用阿拉伯数字（「157 万」）。

## 四、数据：能上屏的数字必须有来源

- 每个数字记下：数值、单位、年份、口径、来源链接。
- 官方统计优先；众包数据（例如 Numbeo）只能作辅助，并在画面角落用小字注明「众包数据」。
- 不同城市或国家的口径不一致时，在画面上写清楚（例如「东京 ≈47 分钟，含上学」）。不要硬凑成同一口径。
- 涉及政策的内容（签证、收费、落户），发布前再核一次最新状态。例子：美国 H-1B 的 10 万美元费用，2026 年仍被法院叫停，片中就不提。
- 对比计算（到手、剩余、倍数）要留下可以复算的脚本。

## 五、声音

- 旁白按段生成（一段对应一个小节），每段前留 0.25 秒、后留 0.45 秒空白；无旁白的章节卡固定 2.2 秒。
- 用语音识别取**逐字时间戳**，再用 difflib 把原稿逐字对齐到识别结果上。这是全片的时间轴：镜头切点、贴纸、字幕都从这里算出来。
- 音乐比旁白低约 15 dB，再以旁白为键做侧链压缩（旁白时再压低 7–10 dB）；整片响度归一到 −14 LUFS，真峰值 −1 dBTP；片尾 1.2 秒画面和声音一起淡出。

---

## 六、素材

- 免费可商用的素材库：Pexels、Mixkit（视频和音乐）。先按「城市 / 场景 / 概念」三类各搜一轮，做缩略图拼图，再人工挑选。
- 选镜头的标准是**能和一句话对上**，而不是好看：讲通勤就用车流和地铁，讲房租就用公寓楼，讲签证就用护照和登机牌。
- 讲解板上的卡片直接用实拍静帧，这样两种画面在视觉上是连着的。
- 下载前确认许可。成品里可以用，但不要把原始素材重新分发（本仓库只保存素材 ID 和链接）。

## 七、工作流和分工（人 / 主模型 / 执行代理）

```
选题与框架 ──► 数据调研（带来源） ──► 配音稿 ──► 生成配音 ──► 逐字时间戳
                                                          │
素材检索与下载 ◄──────────────────────────────────────────┤
                                                          ▼
                                       逐句分镜 beats（每个「@词」触发一个变化）
                                                          │
                     ┌────────────────────────────────────┼─────────────────────┐
                     ▼                                    ▼                     ▼
              图形层（透明 PNG 序列）              字幕层 + SRT           实拍剪辑表（EDL）
                     └────────────────────────────────────┼─────────────────────┘
                                                          ▼
                                     合成（任选一种后端）＋ 混音 ──► 成片 ──► 审片
```

- **人或主模型**负责判断：选题、框架、逐句分镜、挑素材、审片。这几步决定成片好不好，不要外包。
- **执行代理**负责体力活：调研整理、渲染脚本、对齐、批量渲染、拼图、验收脚本。
- 派给执行代理的任务单要写四项：目标、输入、验收标准、回报格式。审美上的要求要写成可以测量的条件（例如「讲解板内容宽度 ≥1100px、水平中心在 960±120px 以内」），否则交回来的版式会缩在角落。

## 八、审片

- 每个 beat 在触发后 0.7 秒取一帧，叠上实拍和字幕，4 列一页拼起来看。
- 再看一张只有讲解板的拼图（触发后 1.2 秒，入场动画已经结束）。
- 短于 0.7 秒的镜头会被抽帧漏掉。判断有没有丢镜头，要查剪辑表，不要只看拼图。
- 成片还要测：总时长、响度、片尾亮度是否降到接近 0，并从头到尾完整看一遍。

## 九、第一版为什么失败（反面清单）

| 做法 | 结果 |
|---|---|
| 暗色电影感、一段旁白只配一个大图形 | 画面空，像宣传片，信息记不住 |
| 镜头在一段旁白内平均切开 | 画面和句子对不上：说到「房租」，画面还是街景 |
| 把「文字简洁」理解成「几乎不上字」 | 观众不知道在讲什么 |
| 没有字幕 | 静音观看（手机上很常见）完全看不懂 |
| 没有参考样片就开工 | 风格靠猜。先找一支喜欢的样片，抽帧拆解它的语汇，再动手 |
