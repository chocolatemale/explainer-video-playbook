# 逐句分镜（第二版）

规则：画面跟着句子走，约每 2–3 秒一个变化；旁白说到哪个词，那个词就以贴纸或高亮的形式出现。
「@词」= 在旁白读到这个词的那一刻出现或切换（按 vo/timing 逐字时间戳对齐原稿）。
F = 实拍满屏（clip 是 footage/raw 里的 Pexels ID）；B = 米白纸张讲解板（不透明，盖住实拍）。

## 视觉规范
- 纸张底 #F4F1E8，墨色 #161616，荧光黄 #FFE03A，红 #E8392F，蓝 #3570E8，绿 #1FA971，灰条 #C9C4B8
- 城市色：上海 红｜深圳 绿｜东京 蓝｜硅谷 黄
- 贴纸类型：
  - tag：白底黑字方块标签，放在画面左上，表示地点或对象（「硅谷」「程序员」）
  - chip-y：荧光黄底黑字圆角块（重点概念）；chip-k：黑底白字（对比项）；chip-g：绿底白字（结论）
  - sticker-r：红底白字，倾斜 −6° 到 −10°，带白描边和阴影，像贴上去的（反转、提醒）
  - kinetic：实拍上的大字，白字 + 4px 黑描边 + 投影，可以带倾斜，并用荧光黄高亮一个词
  - card：讲解板上的素材卡片（从实拍里截的静帧），圆角 10px，白边 6px，投影，左上角带 tag
  - bar：讲解板上的横向彩条，左边是行名（工资／房租／通勤），条上压着小字注释
- 入场：贴纸 0.18 秒弹出（scale 0.6→1.08→1，回弹）；卡片 0.3 秒从下方 30px 上浮淡入；条形图 0.5 秒从左长出；数字滚动计数
- 字幕：每一帧底部居中，白字 + 黑描边，字号约 40px，按标点断句，每屏最多 16 字，不带句末标点
